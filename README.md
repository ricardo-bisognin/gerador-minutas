# Gerador de Minutas

Sistema para geração e instrução inicial de instrumentos administrativos, começando pelos Termos de Cooperação para utilização de mão de obra prisional no RS.

## Primeiro módulo

- cadastro estruturado da solicitação;
- convenente empresa ou município;
- FPE e processo com campos pendentes destacados;
- seleção múltipla de estabelecimentos penais por DRPP;
- atividades dinâmicas com sugestões e normalização de redação;
- local de prestação;
- jornada com alertas não bloqueantes;
- remuneração em texto livre;
- vigência padrão de 5 anos e justificativa obrigatória para prazo inferior;
- armazenamento dos dados estruturados no Supabase;
- preparação para leitura de documentos, geração de TC/PT e envio à área técnica.

O projeto é independente do repositório `convenios-publicos` e do respectivo projeto Supabase.
